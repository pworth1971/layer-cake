## Citing-context issues (MISCITED)

1. **sennrich-etal-2016-neural** (tokenization section). The current sentence reads: "Byte Pair Encoding (BPE) on the other hand, introduced in 2016 \cite{sennrich-etal-2016-neural} … was initially used for data compression and was then later adapted for NLP by the SentencePiece and GPT/GPT-2 models." This is wrong on two counts. BPE was introduced by Gage (1994) as a compression algorithm. Sennrich et al. are the ones who adapted it for NLP (subword segmentation for NMT); SentencePiece and GPT/GPT-2 came later. Suggested text: "Byte Pair Encoding (BPE), originally a data-compression algorithm \cite{gage1994}, was adapted for subword segmentation in neural machine translation by Sennrich et al. in 2016 \cite{sennrich-etal-2016-neural}, and was later adopted by the GPT family of models (GPT-2 uses a byte-level variant) and implemented in SentencePiece \cite{kudo2018sent…}." This also brings the uncited `gage1994` into use.

2. **zhang2022** (caption of Fig. 4). The current caption reads: "LLM input representation - Token, Segment and Position embeddings \cite{zhang2022}". The token + segment + position input-embedding figure is from the BERT paper (Devlin et al., 2019, Fig. 2). zhang2022 is an ALBERT-based relation-extraction paper on Chinese power-sector text and is not the original source. I could not open its full text to see whether it reproduces the figure. Also, segment embeddings are specific to BERT-style models (GPT-style LLMs do not use them), so "LLM input representation" over-generalises. Suggested caption: "BERT input representation: the input embedding is the sum of token, segment and position embeddings (adapted from Devlin et al. \cite{devlin-etal-2019-bert})". If the image file was taken from zhang2022, add "as reproduced in \cite{zhang2022}"; otherwise drop zhang2022.

3. **sheng2024sloraservingthousandsconcurrent** (related-work paragraph on PEFT). The paragraph groups S-LoRA with "related optimization techniques using LoRA like approaches" and then says "these studies focus on comparative performance improvements gains for LLM fine-tuning without a detailed analysis of the underlying computational resource requirements". S-LoRA is an *inference serving system* for many LoRA adapters, and it is mostly about compute resources (GPU memory paging, throughput, serving thousands of adapters on one GPU). QLoRA and LoRA also report GPU-memory and throughput figures. Suggested text: "…as well as systems for efficiently serving many LoRA adapters such as S-LoRA \cite{sheng2024…} and LoRA variants such as SC-LoRA \cite{luo2025…}. While these works report memory and throughput gains for adapting or serving LLMs, they do not compare the computational cost of classical ML, static-embedding and transformer-based approaches for a given classification problem, leaving…". If you use the MLSys 2024 version, note that its title spells the system "SLoRA".

## Minor wording notes (citations are acceptable; text could be tightened)

- **li2020pytorchdistributedexperiencesaccelerating**: "Distributed Data Parallel, scales linearly with the number of GPUs". The paper claims "near-linear scalability using 256 GPUs" "when configured appropriately". Suggest: "…attains near-linear scalability up to 256 GPUs when appropriately configured \cite{…}". The DataParallel description in the other citing sentence is supported: the paper describes DataParallel as single-process, multi-thread, multi-GPU on one machine.
- **liang2022research / zhao2022research / kamyab2021attention**: these are cited for "weight the different tokens [with tf-idf] alongside the attention based masking that the transformer models are known for … effective … like sentiment analysis". None of the three uses transformers. Liang & Niu (TF-IDF + BiLSTM/TextCNN) and Zhou (TF-IDF feature selection + CNN-LSTM) address general text classification; only Kamyab et al. (TF-IDF + GloVe + attention CNN/Bi-LSTM) addresses sentiment analysis. Suggest: "Combining TF-IDF token weighting with neural architectures (CNN/LSTM, with or without attention) has been shown to be effective for text classification \cite{liang2022research} \cite{zhao2022research} and sentiment analysis \cite{kamyab2021attention}." Also, the first author of zhao2022research is Zhou, so do not write "Zhao et al." anywhere in the text.
- **hochreiterlong** (introduction): the 1997 LSTM paper is cited as an example of DL models using word embeddings to push text-classification results. It predates word embeddings and does not address text classification. It is fine as the LSTM architecture reference; consider "…in DL architectures such as CNNs \cite{yoon2014convolutional} and LSTMs \cite{hochreiterlong} …".
- **pearson01111901 / hotelling1933AnalysisOA**: the text says "Principle Component Analysis". It should be "Principal Component Analysis".
- **bahdanau2016neuralmachinetranslationjointly**: Bahdanau et al. motivate attention by the fixed-length-vector bottleneck of encoder–decoder NMT, not by distributional semantics. The hedged wording ("in some sense can be seen as a motivating factor") is acceptable as interpretation, but should not be presented as the authors' stated motivation.
