## Citing-context issues

1. **peters2018deep (ELMo).** The current text calls ELMo one of the approaches "which leveraged transformer architectures and attention mechanisms". ELMo has neither.
   Suggested fix: "Among the early influential deep-learning approaches to contextualized (dynamic) word representations was ELMo (Embeddings from Language Models), introduced in 2018 \cite{peters2018deep}, which derives contextual embeddings from a bidirectional LSTM language model; BERT \cite{devlin-etal-2019-bert} then brought the transformer encoder and self-attention to this setting."

2. **liu2019roberta (cited as a survey).** In "...some notable text classification research surveys that do include both ML and DL approaches, e.g. \cite{liu2019roberta}", RoBERTa is not a survey.
   Suggested fix: replace with `\cite{kowsari2019text, li2022survey}`, the two surveys proposed in batch D. Both were verified in Crossref:
   - Kowsari et al., "Text Classification Algorithms: A Survey", *Information* 10(4):150, 2019, DOI 10.3390/info10040150.
   - Li et al., "A Survey on Text Classification: From Traditional to Deep Learning", *ACM TIST* 13(2), 2022, DOI 10.1145/3495162.

3. **hinton2015distilling (with articlebai), the DeepSeek distillation sentence.** "a distilled DeepSeek model based on techniques similar to those used for optimizing Qwen models" is inaccurate.
   - The model used, DeepSeek-R1-Distill-Qwen-1.5B, is a **Qwen2.5-Math-1.5B** model fine-tuned (SFT only) on about 800k samples generated by DeepSeek-R1. Source: the model card and guo2025deepseek.
   - Suggested fix: "We also include DeepSeek-R1-Distill-Qwen-1.5B, a Qwen2.5 model \cite{yang2024qwen25} fine-tuned on reasoning data generated by DeepSeek-R1 \cite{guo2025deepseek}, i.e. a form of knowledge distillation \cite{hinton2015distilling}." (`yang2024qwen25` is proposed in batch D; otherwise keep `articlebai` only if it is the Qwen report.)

4. **sanh2020distilbert.** "was shown to be ... just as effective" overstates the paper.
   Suggested fix: "...was shown to be nearly as effective, retaining about 97% of BERT's language-understanding performance while being 40% smaller and 60% faster \cite{sanh2020distilbert} (a result our text-classification experiments also bear out)."

5. **touvron2023llama.** "optimized for efficient scaling and multilingual generation tasks" does not describe LLaMA-1, which is a set of English-centric base models without SFT or RLHF. The model actually evaluated is Llama-3.2-1B.
   - Suggested fix: "Llama, introduced by Meta in 2023 \cite{touvron2023llama}, is a family of decoder-only, autoregressively trained transformer LLMs; the model used here, Llama-3.2-1B, belongs to the Llama 3 generation, which added multilingual support \cite{grattafiori2024llama3}." (`grattafiori2024llama3` is in batch D.)
   - If the nearby sentence "...are also tuned using SFT and RLHF" refers to Llama, it applies only to the chat/instruct variants. The code loads the base checkpoint.

6. **ouyang2022training (and guo2025deepseek).** The text says "DeepSeek models utilize reinforcement learning without preliminary SFT \cite{ouyang2022training}". InstructGPT is SFT followed by RLHF, so it does not support this. Also, only DeepSeek-R1-Zero skips SFT: DeepSeek-R1 adds a cold-start SFT stage, and the distilled model used here is SFT-only.
   Suggested fix: "DeepSeek-R1-Zero was trained with large-scale reinforcement learning without a preliminary supervised fine-tuning stage, and DeepSeek-R1 adds a small cold-start SFT stage before RL \cite{guo2025deepseek}, in contrast to the SFT-then-RLHF pipeline of InstructGPT \cite{ouyang2022training}; both incorporate chain-of-thought reasoning \cite{articlewei}."

7. **sinha (arXiv dataset).** The Microsoft Academic Service paper is not the source of the arXiv dataset. The code loads the Cornell arXiv metadata snapshot.
   Suggested fix: cite Clement et al., "On the Use of ArXiv as a Dataset", arXiv:1905.00075, 2019 (ICLR 2019 RLGM workshop; verified via the arXiv API), and/or the Kaggle dataset as `@misc` with `howpublished = {\url{https://www.kaggle.com/datasets/Cornell-University/arxiv}}`. A ready entry:
   `@article{clement2019use, title={On the Use of {ArXiv} as a Dataset}, author={Clement, Colin B. and Bierbaum, Matthew and O'Keeffe, Kevin P. and Alemi, Alexander A.}, journal={arXiv preprint arXiv:1905.00075}, year={2019}}`
   Also check the "58 scientific disciplines" count against the label set the code actually produces.

8. **farhangi (arXiv protoformer).** The citation is correct, since ArXiv-10 was introduced in the Protoformer paper, but the description is not. The paper says the authors *crawled* 100k arXiv titles and abstracts from ten research categories (subcategories of CS, physics and math), downsampled to 10k per category. It does not say this is a subset of the arXiv dataset, does not say the categories are "the 10 most common", and does not support "frequently used for prototype-based models".
   Suggested fix: "**ArXiv-10** \cite{farhangi}: a single-label, balanced dataset of 100,000 arXiv paper titles and abstracts from ten research categories (10,000 per category), introduced with the Protoformer model."

9. **sanderson (OHSUMED).** Replace with `\cite{hersh1994ohsumed}`, already proposed in batch D. That is Hersh, Buckley, Leone and Hickam, "OHSUMED: An Interactive Retrieval Evaluation and New Large Test Collection for Research", SIGIR '94, pp. 192–201, DOI 10.1007/978-1-4471-2099-5_20, verified in Crossref. Add `\cite{joachims1998text}` for the 23 MeSH disease-category version, which batch D is checking.

### Other wording notes (the citation is fine; the sentence is slightly off)

- **radford2019language footnote.** "called *causal* language models due to the determinative nature of the underlying algorithm" is wrong. "Causal" refers to the left-to-right (causal) attention mask: each token is predicted only from the tokens before it. Suggested text: "...called *causal* language models because each token is predicted only from the tokens that precede it."
- **RoBERTa/BERT sentence.** "BERT ... which was released in 2019". BERT was released in October 2018 (arXiv:1810.04805) and published at NAACL 2019; the devlin key is in another batch. RoBERTa (July 2019) is correctly dated.
- **lewis1987reuters.** "21,578 news documents across 115 categories" mixes two things. 21,578 is the size of the whole collection, while Lewis's README lists 135 TOPICS categories (120 that occur at least once). The figure 115 presumably comes from the experimental split. State the split (e.g. ModApté, following \cite{moreo2021}) with its document and category counts.
- **greene (BBC News).** The classes are "roughly balanced", not "balanced": 510 / 386 / 417 / 511 / 401 documents, counted from `bbc.classes` in the official archive.
